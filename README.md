
<td width="50%" valign="top">

### 💰 FlowFin
Controle financeiro pessoal construído do zero — sem framework, sem abstração. O objetivo é dominar as fundações antes de usar o que está em cima.

**O que vai resolver:** ter clareza real sobre onde o dinheiro vai, sem depender de app de terceiro.

`HTML` `CSS` `JavaScript` `Node.js` `Express` `PostgreSQL`

**Status:** `🔨 em desenvolvimento`

```
Fases do projeto
 ├── JS puro → Node.js → HTTP
 ├── Express → PostgreSQL → CRUD
 ├── Frontend → integração → dashboard
 └── Auth → deploy → documentação
```
